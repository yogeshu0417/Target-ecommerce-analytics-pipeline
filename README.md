# Target E-Commerce Analytics Pipeline & Market Intelligence

An end-to-end analytics project analyzing customer behavior, product ratings, regional sales, and sentiment trends.

## 📌 Project Architecture
- **Data Cleaning & Pipeline**: Python ETL scripts (`clean_data.py`)
- **Database & Query Layer**: SQLite/PostgreSQL schemas with optimized SQL queries
- **BI & Visualizations**: Interactive dashboard and Power BI analytical charts
- **Business Reporting**: Customer behavior analysis & executive summaries

## 📊 Key Highlights
- Cleaned and normalized transactional datasets across customer, product, and review entities.
- Generated SQL aggregations for customer lifetime value (LTV), sentiment distribution, and regional revenue.
- Visualized monthly trends, age band spending, and rating distributions.
